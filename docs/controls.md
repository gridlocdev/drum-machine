# Controls

|                            | Keyboard                         | Mouse or touch |
| -------------------------- | -------------------------------- | -------------- |
| Play a drum                | `Q` `W` `E` `A` `S` `D` `Z` `X` `C` | Click or tap its pad |
| Start a sample loop        | `1` to `9`                       | Pick it from **-- Select a sample --** |
| Pause or resume the loop   | `Space`                          | **▶ / ⏸** |
| Reverse on or off          | `R`                              | **⇆** |
| Slow down or speed up      | `←` `→` (0.1x a press)           | The speed slider |
| Volume down or up          | `↓` `↑` (5% a press)             | The **Volume** slider |
| Show or hide the shortcuts | `?`                              | **Help** (not shown on touch screens) |
| Close the shortcuts        | `Esc`                            | **×**, or click outside it |

Which drum each letter plays is listed in [Features](features.md#drum-pads). Keys are matched as typed, so with Caps Lock on the letter keys don't play.
